# การจัดการคลังสินค้า

เว็บแอปสำหรับจัดการสินค้าและสต็อก ใช้งานผ่านไฟล์ `index.html` ได้ทันที โดยไม่ต้องติดตั้งเฟรมเวิร์กเพิ่มเติม

## ฟังก์ชันหลัก

- แผงควบคุมสรุปยอดขาย ยอดค้างรับ ยอดค้างจ่าย และสินค้าที่ใกล้หมด
- จัดการสต็อกสินค้า เพิ่ม แก้ไข ลบ และกำหนดจุดสั่งซื้อ
- จัดการผู้ผลิตและลูกค้า
- บันทึกการจัดซื้อและเพิ่มสต็อกอัตโนมัติ
- บันทึกการขายและตัดสต็อกอัตโนมัติ พร้อมแจ้งเตือนเมื่อสินค้าไม่พอ
- รับชำระเงินและจ่ายเงินเจ้าหนี้แบบเต็มจำนวนหรือแบ่งชำระ
- รายงานยอดขาย กำไร และยอดค้างรับ/ค้างจ่าย
- สำรองและนำเข้าข้อมูลด้วยไฟล์ JSON

## วิธีใช้งาน

เปิดไฟล์ `index.html` ด้วย Google Chrome หรือ Microsoft Edge แล้วกด “โหลดข้อมูลตัวอย่าง” หากต้องการทดสอบระบบอย่างรวดเร็ว

## การเปิดเป็นเว็บด้วย GitHub Pages

1. เข้า Settings → Pages ของ repository
2. เลือก Source เป็น Deploy from a branch
3. เลือก branch `main` และโฟลเดอร์ `/ (root)`
4. บันทึกการตั้งค่า

## การจัดเก็บข้อมูล

ระบบเก็บข้อมูลใน localStorage ของเบราว์เซอร์ จึงควรสำรองข้อมูลเป็นไฟล์ JSON เป็นระยะ โดยข้อมูลจากแต่ละเครื่องหรือแต่ละเบราว์เซอร์จะไม่แชร์กันอัตโนมัติ

## เทคโนโลยี

HTML, CSS และ JavaScript แบบไฟล์เดียว ไม่ใช้ framework
